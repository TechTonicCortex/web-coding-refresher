HTML: the bones

HTML says what is on the page: headings, paragraphs, buttons, lists, inputs. Tags come in pairs like <p>…</p>.

CSS: the looks

CSS says how it looks. You pick elements with a selector (.card means class="card") and set properties inside { }.

JavaScript: the brains

JavaScript makes the page do things: react to clicks, read what you typed, change text, and talk to APIs. Not the same as Java!

Mini project: a quiz app

Put it all together. This is hackathon-sized: you should be able to finish and improve it in one sitting. There is no Check button, because you decide when it's good.

Start small

Get one question working end to end before adding more. A working small app beats a broken big one.

Test often

Press Run after every few lines. If something breaks, you know it was the last thing you changed.

Can you explain it?

Judges ask how it works. If you use AI help, make sure you understand every line.
